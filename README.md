Mini E-Learning Platform

Project Description
This is a frontend-based mini e-learning platform that allows users to browse available courses, view lessons, and track course completion using local storage. The project demonstrates the use of HTML, CSS, and JavaScript to build an interactive learning interface.

Features
- Display available courses dynamically
- View course details and lessons
- Mark courses as completed
- Progress persistence using Local Storage
- Responsive and clean user interface

Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Browser Local Storage

How to Run the Project
1. Download or clone the repository
2. Open `index.html` in any modern web browser
3. Click on a course to view details and lessons


Future Improvements
- User authentication
- Quiz and assessments
- Video lessons
- Backend integration
- Admin dashboard
